【iPhoneからGitHubへアップロードする手順】

1. このZIPはiPhoneの「ファイル」アプリで解凍してください。
2. GitHubの pharmacy-management リポジトリをSafariで開きます。
3. Add file → Upload files を選びます。
4. 解凍したフォルダ内の次の2ファイルを両方選択します。
   ・index.html
   ・pharmacy-weekly-review-bg.jpeg
5. 2ファイルともリポジトリ最上位（現在のindex.htmlと同じ場所）へアップロードします。
6. Commit changes を押します。
7. 1〜3分後、Safariでページを再読み込みします。
8. 古い表示が残る場合は、URL末尾に ?v=2 を付けて開きます。

注意：ZIPファイル自体をGitHubへアップロードしても展開されません。
必ずZIPを解凍し、中の2ファイルをアップロードしてください。
